# LoyScan

Your loyalty cards on your phone. Offline, with no account and no ads.

An Android app (Kotlin, Jetpack Compose). How it is built, and why, is in the project wiki: start at
[`wiki/index.md`](wiki/index.md). Building and running: [`wiki/workflows/build-and-run.md`](wiki/workflows/build-and-run.md).

LoyScan is not affiliated with any of the retailers whose cards it can hold.
